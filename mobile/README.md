# XRP Forecast — mobile app

Expo (SDK 58) / React Native 0.88 app that shows the forecasts from the
[forecast API](../README.md#http-api): XRP/USD price history, the median
forecast with 50% and 90% ranges, and how the model did in backtests.

> **Not financial advice.** The disclaimer is pinned on every screen state,
> including loading and errors.

## Run it

```bash
# 1. API (from the repo root)
pip install -r requirements-api.txt
uvicorn xrp_forecast.api:app --host 0.0.0.0 --port 8000

# 2. App
cd mobile
npm install
npx expo start         # then press i / a / w, or scan with Expo Go
```

In development the app calls `http://localhost:8000` (or
`http://10.0.2.2:8000` from the Android emulator). On a physical device, point
it at your machine:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.20:8000 npx expo start
```

Release builds **require** `EXPO_PUBLIC_API_URL` to be an `https://` URL. If
it isn't, the app shows "not configured" instead of making an insecure call.

## Checks

```bash
npm run check   # typecheck + lint + prettier --check + jest
```

`expo-env.d.ts` is generated by `npx expo start` and is git-ignored. Run
`expo start` once after cloning, or `tsc` will report missing CSS module
types.

## How it works

| Path                        | Role                                                                                           |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| `src/app/index.tsx`         | Forecast screen: horizon picker, price, chart, summary, backtest                               |
| `src/hooks/use-forecast.ts` | Shows the saved forecast first, then the network; handles cancellation and retries             |
| `src/api/client.ts`         | `fetch` with a 15 s timeout; maps every failure to a `ForecastError` kind                      |
| `src/api/validate.ts`       | Runtime validation of the response; anything misleading is rejected, not drawn                 |
| `src/api/cache.ts`          | Last good forecast per horizon in AsyncStorage (public market data only), re-validated on read |
| `src/lib/chart.ts`          | Pure log-scale chart geometry, unit-tested                                                     |

### Customer journey: what the user sees

| Situation                                                                              | Behaviour                                                                                                                               |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| First load                                                                             | Spinner, then the forecast                                                                                                              |
| Switch horizon                                                                         | Request for the old horizon is aborted; a late answer can never overwrite the new one                                                   |
| Pull to refresh                                                                        | Current forecast stays on screen while it reloads                                                                                       |
| Offline, forecast saved earlier                                                        | Saved forecast shown with "Showing forecast saved 3 h ago", plus Retry                                                                  |
| Offline, nothing saved                                                                 | "You're offline…" with Retry                                                                                                            |
| Refresh fails while data is shown                                                      | Data kept, "Couldn't refresh" banner with Retry                                                                                         |
| Price feed down (API 503)                                                              | "Price data is temporarily unavailable. Try again in about a minute."                                                                   |
| Request hangs                                                                          | Times out after 15 s, with Retry                                                                                                        |
| Response incomplete or inconsistent (crossed quantiles, NaN, wrong horizon, truncated) | Rejected and never drawn: "came back incomplete"                                                                                        |
| Saved forecast corrupted or from an older schema                                       | Discarded and deleted from the device                                                                                                   |
| Prices old (server `stale` flag, or last close more than 2 days old)                   | Data shown with a "Prices may be out of date" warning                                                                                   |
| 90% band too wide to plot (long horizons)                                              | Axis capped so history and the 50% band stay readable; note says the outer band runs off the chart, and exact values are in the summary |
| Model no better than "no change" in backtests                                          | Warning: treat the direction as noise and read the ranges                                                                               |
| 90% range caught under 80% of past outcomes                                            | Warning that the ranges have been too narrow                                                                                            |
