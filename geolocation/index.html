    Satellite data: what a web page can and cannot see

    Phones fuse GNSS satellites (GPS, GLONASS, Galileo, BeiDou), Wi‑Fi, cell towers and motion sensors into one position. The W3C Geolocation API hands a web page only the fused result. Satellite count, signal strength, constellation and DOP values stay inside the operating system. The “likely source” above is inferred from accuracy and altitude, and the page labels it as an inference.
